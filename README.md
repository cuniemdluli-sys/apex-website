# Apex EcoTech Solutions — Sustainable IT & Green Tech

A responsive, single-page web application built for **Apex EcoTech Solutions (Pty) Ltd** as part of the **WEDE5020** module. This project showcases modern, green IT solutions—such as infrastructure auditing, e-waste management, and solar monitoring—tailored for South African enterprises.

---

## Key Features & UI Enhancements

### 1. Modern Layout & Styling
* **CSS Custom Properties**: Centralized color variables (`--primary`, `--dark-bg`, `--light-bg`, etc.) ensuring consistent branding and easy maintenance.
* **Responsive Flexbox & CSS Grid**: Flexible card layouts (`.services-grid`, `.about-container`) built to adjust seamlessly across mobile, tablet, and desktop viewports.
* **Hero Banner**: High-contrast, dark overlay hero section with custom typography and clear call-to-action buttons.

### 2. Interactive Components
* **Mobile Navigation**: Hamburger menu toggle implemented with Vanilla JavaScript for small screen support.
* **Custom Forms**: Styled form inputs, select dropdowns, and textareas for client consultation and audit requests.
* **Form Handling**: Client-side submission listener with user notification and automatic form resetting.

---

## Technical Stack

* **HTML5**: Semantic elements (`<header>`, `<section>`, `<nav>`, `<footer>`) ensuring accessbility and structural clarity.
* **CSS3**: CSS Grid, Flexbox, media queries, CSS variables, hover micro-interactions, and visual feedback states.
* **JavaScript (ES6+)**: DOM manipulation for navigation toggles and form submission handling.
